# 离线 RAG 合成 Fixture

本目录所有内容均为项目自行编写的合成测试资料，不含真实车辆资料、个人数据、联网依赖或第三方受限内容。

- `pdf/`：由 `PdfFixtureFactory` 在测试工作目录生成，避免提交来源不明的二进制文件。
- `static_html/` 与 `markdown/`：验证本地静态解析、标题路径、表格与 Locator。
- `security/`：只用于验证脚本、iframe、远程资源和 file 链接不会被执行或读取。
- `cross_format/`：同一合成知识的跨格式表达；其 Golden 变更必须说明协议或解析规则变化原因。
- `golden/`：只保存稳定、无敏感信息的预期摘要，不得使用“重录全部 Golden”掩盖回归。

许可：本仓库测试代码随项目许可证使用。
